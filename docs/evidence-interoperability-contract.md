# Evidence interoperability contract — draft v0.1

Status: **experimental**, not a published standard. This document describes the current Gate B implementation and explicit limits.

## What this project does

Compare the *declared scopes* of a pinned structural AAS JSON validator (OpenDPP) and a separately maintained AAS metamodel/constraint validator (`aas_test_engines`). Preserve actual input bytes and execution evidence so others can replay the comparison. A disagreement is a **COVERAGE_DIFFERENCE**, not proof of an upstream defect.

## Inputs and trust boundaries

1. `report.json` is generated by real pinned upstream CLI runs. `overall=REPLAY_OUTCOME_MATCH` is necessary but not sufficient.
2. `aas-oracle-observation.json` is generated by invoking `aas_test_engines.file.check_json_data`. The installed distribution must match `1.0.3`, and `ok()` must return a strict boolean.
3. The independent comparator checks the actual bytes of `primary-baseline.json` and `primary-mutant.json` against the SHA-256 values in both reports; rejects missing files, symlinks, extra/duplicate oracle records and unexpected oracle/version identifiers.
4. If any prerequisite fails, the comparison returns `NOT_COMPLETED` with **no published cases**. A completed comparison has exactly two cases.
5. `OBSERVED` means a comparison was performed. It does **not** mean AAS conformance, independent hardware replay, or third-party endorsement.

## Horizontal audit and dependencies

| Component | Depends on | Failure behavior | Evidence | Status |
|---|---|---|---|---|
| Pinned OpenDPP CLI | Git checkout, npm ci, sample inputs | Nonzero / fail | report.json and raw stdout/stderr | Previously observed in public Actions |
| OpenDPP API-to-CLI contract | Same pinned upstream API | Fail when results diverge | external-module-contract.json | Previously observed in public Actions |
| Official AAS Test Engines adapter | Pinned installed Python distribution | NOT_COMPLETED | aas-oracle-observation.json | Previous public run; new hardening awaiting CI |
| Cross-validator comparison | CLI report, oracle report, actual input bytes | NOT_COMPLETED, zero cases | cross-validator-comparison.json | New hardening awaiting CI |
| Independent acceptance | All prerequisite evidence | Fail closed | independent-acceptance.json | Previous public run; new CI awaiting verification |

## Independent negative tests

Tampered input bytes, symlink input, duplicate oracle rows, changed oracle identity/version, non-boolean verdict, missing module, incorrect installed distribution, and failure of the second input after the first passed. The latter must not expose partially verified comparison cases.

## Not yet delivered

- End-to-end CI receipt for the new PR head
- Independent-machine / independent-organization replay
- Machine-readable evidence schema, stable versioning and provenance signatures
- Broader IDTA 3.x version and AASX input coverage
- Independently reviewed semantic labels and a documented standards rule coverage matrix
- Third-party adoption, upstream acceptance, and completed 17-story legacy migration

## Strategic criterion

Prefer contributions that another independent validator, standards reviewer or CI maintainer can **import, reproduce and cite**. Do not count stars, commits or passing mocks as third-party adoption. If no external reviewer adopts the evidence format, reconsider the niche before expanding the platform.
